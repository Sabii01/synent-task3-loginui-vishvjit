# Modern Login Page UI

A responsive and modern Login Interface designed with clean UI aesthetics, semantic HTML5, and responsive CSS3.

## Features
- Clean and modern card layout with radial background styling
- Custom input fields with active focus states
- Remember me checkbox and Forgot Password interactive links
- Responsive layout supporting both mobile and desktop screens

## Tech Stack
- HTML5
- CSS3 (Flexbox, CSS Variables, Media Queries)
